# Локальная русская озвучка для игры

Подготовлен самостоятельный HTTP-модуль на Qwen3-TTS-12Hz-0.6B-Base.
Это кандидат для NVIDIA с 6 ГБ VRAM, а не подтверждение, что памяти хватит
при одновременно запущенной игре. Используются BF16 (если поддерживается), SDPA, одна генерация
за раз и заранее вычисленный голосовой образец. CPU-подмена не выполняется.

**Статус на 2026-11-01:** модель Пина `pin-v2` дообучена на Tesla-сервере,
две новые игровые фразы сгенерированы и распознаны Whisper turbo без ошибок слов.
На целевой видеокарте игрока синтез пока не проверен. Стандартный qwen-tts API
сначала генерирует реплику целиком, затем возвращает WAV. Это ещё не потоковый
синтез с гарантированной работой в реальном времени.

## Обученная модель Пина

На сервере: `/mnt/models/pin-tts/runs/pin-v2/model`, голос `pin`.
Размер папки около 2,4 ГБ. Выбрана эпоха 4 из 10 по ошибке на двух отложенных
фрагментах. Набор очень мал: 8 обучающих фрагментов и 2 проверочных; использованы
выбранные реплики очищенного монолога и синтетические примеры с AiHere.
Часть расшифровок автоматическая; сходство голоса человеком не оценено.

На V100 тест в BF16 занял 10,09 и 10,34 секунды для 3,76 и 4,08 секунды речи.
Пиковая память тензоров — 2,22 ГиБ, резерв PyTorch — 2,47 ГиБ, без учёта других
процессов и накладных расходов драйвера. Эти числа не являются замером на RTX 30
и не подтверждают одновременную работу с игрой в пределах 6 ГБ.

Чтобы скопировать прошедшую проверку модель с этого компьютера на локальный диск:

```powershell
scp -r tesla-server:/mnt/models/pin-tts/runs/pin-v2/model models/pin-v2
```

Перед копированием создайте папку `models`; папка `models/pin-v2` должна отсутствовать,
иначе SCP может создать дополнительный уровень `model`.
После установки окружения запустите `start-pin.cmd` или:

```powershell
.\.venv\Scripts\python.exe local_tts.py --model models/pin-v2 --speaker pin
```

`auto` выбирает BF16 при доступности в PyTorch, иначе FP32 на GPU.
FP16 дал нечисловые вероятности в первом тесте и не используется по умолчанию.
Старый эксперимент `pin-v1` отклонён; запускатель указывает только на `pin-v2`.

Демонстрации и отчёты находятся в `artifacts/audio-cleanup/pin-trained` относительно
корня проекта. Серверные скрипты и журнал: `/home/stas/projects/pin-tts-training`.

## Установка на компьютере, где запускается игра

Нужны Python 3.12, NVIDIA-драйвер и PyTorch с CUDA.
Создайте отдельное окружение в этой папке:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install torch --index-url https://download.pytorch.org/whl/cu126
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Первый запуск скачает веса из Hugging Face. После скачивания установите
`$env:HF_HUB_OFFLINE="1"`, чтобы проверить запуск без интернета. Можно также
передать `--model` с путём к полностью скачанной папке модели.
Озвучка выполняется на компьютере; текст и запись в облачный TTS не отправляются.

## Голос и запуск

Подготовьте `voice.wav`: один чистый фрагмент речи длиной 3–30 секунд без
музыки и других говорящих. В `voice.txt` запишите ровно произнесённые слова
в UTF-8. Из более длинного примера выберите подходящий фрагмент с расшифровкой.
В этом режиме используется клонирование по образцу; для обученного голоса
используйте режим `--speaker pin` выше.

```powershell
.\.venv\Scripts\python.exe local_tts.py --reference voice.wav --transcript voice.txt
```

Процесс держит модель в GPU до закрытия окна. API слушает только 127.0.0.1:18765.
`GET /health` возвращает готовность после загрузки. Порт можно менять через
`--port`, адрес браузерной игры — через `--origin http://localhost:5173`.

## Подключение игры

Запрос: `POST http://127.0.0.1:18765/speech`, JSON `{"text":"Привет! Добро пожаловать на Марс."}`.
Ответ: WAV PCM16. Лимит — 200 символов, отправляйте короткие законченные фразы.
Во время генерации следующий запрос получает HTTP 429; игра должна держать
свою очередь или пропускать устаревшие реплики. Последние 16 коротких реплик
кэшируются в RAM. Перезапуск очищает кэш и заново считывает образец голоса.

Пример для браузерной игры (запускать после пользовательского нажатия,
чтобы браузер разрешил звук):

```javascript
async function speak(text) {
  const response = await fetch('http://127.0.0.1:18765/speech', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ text }),
  });
  if (!response.ok) throw new Error(await response.text());
  console.log('Synthesis seconds:', response.headers.get('X-TTS-Seconds'));
  const url = URL.createObjectURL(await response.blob());
  const audio = new Audio(url);
  audio.addEventListener('ended', () => URL.revokeObjectURL(url), { once: true });
  audio.addEventListener('error', () => URL.revokeObjectURL(url), { once: true });
  try { await audio.play(); }
  catch (error) { URL.revokeObjectURL(url); throw error; }
  return audio;
}
```

Для проверки задержки возьмите несколько разных коротких русских фраз:
первый запуск учитывает прогрев, повтор одной фразы измеряет только кэш.
Сравните `X-TTS-Seconds` с длительностью WAV и оцените ожидание первого звука
при работающей игре. При нехватке VRAM уменьшите графические настройки игры
либо используйте предварительную генерацию постоянных реплик.
Не увеличивайте длину реплик: лимит генерации может обрезать длинную речь.

Автоматическое включение в игровой клиент пока не выполнено: нужен выбор
игровых событий, которые требуется озвучивать.
