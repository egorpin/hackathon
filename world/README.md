# Карта мира

Генератор и непрерывная сферическая геометрия находятся в `server/app/world/`, игровые правила — в `server/app/game/`. Контракты, баланс и следующий шаг интеграции описаны в [INTEGRATION.md](INTEGRATION.md).

Экспорт серверной карты из корня репозитория:

```bash
PYTHONPATH=server python3 -m app.world.export --output world/generated
```

По умолчанию: радиус 30 м, 642 клетки (12 пятиугольников, 630 шестиугольников), 43 связных чанка размером до 16 клеток, четыре потенциальные посадочные площадки. `manifest.json` содержит версию, размеры UTF-8 и SHA-256 файлов. Полная карта находится только на сервере; не копировать её в `client/public` или клиентскую сборку.

`fixtures/small/` — воспроизводимый пример для интеграции: 42 клетки, радиус 30 м, чанки до 8 клеток, версия `icosphere-v1-s1-r30-c8`. Это геометрический fixture, а не игровая карта с настроенной дистанцией взаимодействия.

Манифест учитывает **только статические чанки**. Оболочка, динамические данные, выбор области интереса и ограничение общего кеша до 10% подключаются участником 2 отдельно; этот экспорт сам по себе ещё не обеспечивает бюджет кеша.

Проверка игрового модуля без внешних зависимостей:

```bash
PYTHONPATH=server python3 -m unittest discover -s server/tests -p test_game.py -v
```
