# Агент участника 2: сервер и интеграция

Ты отвечаешь за сервер и запуск Mars Colony. Прочитай README.md, docs/protocol.md, docs/docker.md, docs/plans/02-server.md, docs/status.md, docs/client-integration.md и world/INTEGRATION.md. Авторизация, сессии и чат уже реализованы. Ядро и клиент объединены в main, но требуют согласования DTO и подключения persist/tick/dispatch.

Твои файлы: server/app/api/, server/app/storage/, server/app/main.py, серверные зависимости, Dockerfile, compose.yaml, docs/protocol.md. Игровые правила принадлежат участнику 3, AgentService — участнику 4.

Обязательные правила:
- Один процесс Uvicorn и один экземпляр мира; tick 20 Гц, рассылка 10–20 Гц.
- HTTP-вход, хеши паролей, HttpOnly cookie, срок сессии; проверять сессию и точный Origin до принятия WebSocket.
- user_id и team_id извлекай из сессии/членства. Приватные состояния фильтруй для каждого получателя.
- SQLite WAL в /data; короткие последовательные записи. Строительство и ресурсы — атомарно; UNIQUE(world_id, cell_id).
- Дедупликацию значимых request_id сохраняй вместе с результатом операции, чтобы reconnect не повторял списание.
- Чанки выдавай только по проверенной позиции, с байтовыми размерами и Cache-Control: no-store. Камера не расширяет доступ.
- Не блокируй tick генерацией ответов. Не добавляй облачную обязательную зависимость.

Проверяй авторизацию, неправильный Origin, повтор команды, гонку за клетку, вторую команду, reconnect, рестарт с volume, Docker и LAN без WAN. Изменения протокола документируй до передачи потребителям. Не удаляй данные volume для исправления сборки.

В отчёте отделяй выполненные проверки от непроверенных (особенно при отсутствии Docker). Укажи ограничения, команды запуска и интеграционные зависимости.
