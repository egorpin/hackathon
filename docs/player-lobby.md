# Лобби игроков

После входа клиент открывает общее лобби. Оно показывает подключённых к этому миру игроков: аватарку, логин и статус «Готов / Не готов». Кнопка «Готов» переключается в «Отменить готовность». Когда готовы все подключённые участники и их мир загружен, сервер запускает экспедицию, а клиенты автоматически закрывают лобби после получения игрового состояния.

До старта лобби нельзя закрыть крестиком или Escape. После старта его можно открыть по аватарке в шапке и вернуться в игру. Сохранённый мир также требует готовности текущих подключённых игроков. До общего подтверждения симуляция приостановлена.

Несколько вкладок одного аккаунта считаются одним игроком. После отключения последней вкладки игрок исчезает из списка; при новом подключении готовность сбрасывается. Если после выхода неготового игрока все оставшиеся готовы, игра запускается. Подключение нового участника до старта добавляет его как неготового. Список ограничен текущим миром; приватные данные команд в нём не передаются.

Настройки упрощены: вариант аватарки и цвет. Они сохраняются в localStorage отдельно для аккаунта. Цвет и вариант передаются другим участникам через сервер; логин всегда берётся из авторизованной сессии. Внешних сервисов и изображений нет.

## WebSocket

- `lobby.state` (сервер → клиент): `{stage, players:[{user_id,username,ready,avatar}]}`.
- `lobby.ready` (клиент → сервер): `{ready:boolean}`. Это временное состояние подключения, оно не переотправляется после reconnect.
- `lobby.profile` (клиент → сервер): `{color:0..5,variant:0..9999}`.
- `lobby.error`: `{code}` при неверных данных или неподходящем этапе.
- Прямой клиентский `world.start` отклоняется с `READY_REQUIRED`. Внутренний запуск разрешает сервер лобби.

Состав лобби и готовность хранятся в памяти сервера. Игровой прогресс сохраняется прежним механизмом SQLite. Переход к игре выполняется без await между проверкой общего голосования и командой запуска.

Режим `?fixture` остаётся только просмотром геометрии, без имитации других игроков и готовности.

Проверки: `npm test`, `npm run build` в client; `python -m pytest -q` из корня; браузерный сценарий `client/tests/lobby-check.cjs` (переменные LOBBY_BASE_URL и PLAYWRIGHT_MODULE при необходимости).
