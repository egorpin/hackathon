# Импорт пользовательского космонавта

Ветка: `codex/models-and-animations`, создана после `git pull --ff-only` и обновления из `origin/main`.

Актуальная игровая модель хранится в `client/public/assets/models/astronaut.glb`. Это единственная опубликованная версия персонажа; промежуточные исходники и скриншоты не хранятся в репозитории.

## Контракт готового GLB

- `client/public/assets/models/astronaut.glb`, включённый в `manifest.json` после проверки экспорта.
- Y-up, ступни на Y=0, высота в нейтральной позе 1,8 м, лицо направлено в +Z.
- Скелет без отдельных пальцев. Клипы: `Idle`, `Walk`, `Run`, `Jump`.
- Руки — отдельные skinned mesh с `Left`/`Right` и `Arm`/`Hand` в имени; весь скелет сохраняется при клонировании для первого лица.
- Материалы с префиксом `AstronautSuit` используют исходную текстуру. Клиент меняет только оранжевые/красные панели через shader uniform; белые и тёмные части сохраняются.

Игровой масштаб берётся из `character-scale.js`, поэтому нормализованный экспорт и текущая небольшая высота персонажа — разные величины. Для ориентации в мире клиент учитывает +Z перед модели.

## Руки и цвет

Старые процедурные руки удалены. Пока GLB загружается, руки не показываются; при ошибке загрузки выводится уведомление. `FirstPersonHands` клонирует скелет и материалы рук, скрывает остальные меши и переключает клипы по движению. Цвет рук и персонажа использует общий `recolor()`.

Для каждого игрока создаются независимые материалы и скелет. Изменение цвета не перезаписывает PNG и не меняет цвет чужого персонажа. Исходные текстуры разделяются экземплярами; при удалении экземпляра они не уничтожаются.

## Проверка

Текущая игровая модель использует очищенную текстуру 1024×1024 без мелких вкраплений
(`tools/models/clean_character.py`). Пользователь подтвердил перед модели по -Z:
визор спереди тёмный, задняя часть шлема белая. В клипе Jump колени сгибаются
к передней стороне на 90°. Руки от первого лица используют отдельную копию скелета.

После `npm run build` откройте `/character-review.html` на игровом сервере. На странице есть выбор анимации, цвета, показ скелета, переключатель первого лица и повтор движения. Это отдельная страница проверки модели, не настройка игрового лобби.

Проверьте сгибы плеч, локтей, бёдер и коленей во всех клипах, отсутствие видимого тела в режиме рук, изменение только цветных панелей и отсутствие ошибок браузера. У прыжка один цикл с удержанием конечной позы до смены состояния.

```powershell
.venv/Scripts/python.exe tools/astronaut/validate_import.py client/public/assets/models/astronaut.glb
cd client
npm test
npm run build
```

Структурные тесты проверяют skin/weights/клипы; они не заменяют визуальную оценку деформаций.

## Риг по пользовательской разметке

Точные исходные точки сохранены в `tools/astronaut/landmarks-user.json`. Новый скрипт `rig_from_landmarks.py` принимает исходный GLB, этот JSON и путь результата. Он переводит Y-up в Blender Z-up. Названия Left/Right и координаты сохраняются в точности как указал пользователь; знак X используется только для направления движения, а не для переименования костей. Риг содержит 16 костей и сохраняет исходные 1 000 треугольников в трёх непересекающихся мешах.

В середине `Jump` бёдра поднимаются к корпусу, колени сгибаются, в конце ноги распрямляются. Высота полёта остаётся серверной; клип не добавляет второе перемещение вверх. В просмотрщике доступны пауза и ползунок для проверки любой фазы. Разметка суставов не является автоматическим одобрением весов и окончательных анимаций: их следует оценить отдельно.
