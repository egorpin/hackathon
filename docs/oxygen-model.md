# Генератор кислорода

Источник: пользовательская модель `PixelArtistry_lowpoly_00015.glb`.
Игровой файл: `client/public/assets/models/oxygen_generator.glb`.

Обработка: `tools/models/optimize_base.py INPUT.glb OUTPUT.glb --straight-panels`.
Размер: 5 751 024 → 71 212 байт. Текстура: палитровый PNG 1024×1024,
без мелких вкраплений, границы цветов проходят по граням модели.
Геометрия сохранена; ширина 1.6 м, основание выровнено по Y=0.
Цветные панели окрашиваются в цвет игрока. Под зданием бетонный фундамент.

Добавлена непрерывная слабая вибрация корпуса компрессора по X/Y;
фундамент неподвижен. Это визуальный эффект: производство O₂ остаётся
отключённым в текущей серверной логике.

Просмотр: `/base-review.html?model=oxygen_generator`.
