Зависимости: участник 3 владеет изменением мира и проверками правил; участник 4 — answer и персональной памятью через storage; участник 1 — транспортом браузера. Изменения протокола немедленно фиксировать и согласовывать с потребителями.

Готово: четыре LAN-клиента, серверная истина, атомарность, идемпотентность значимых команд, изоляция команд/памяти, сохранение, ограниченная выдача чанков и офлайн-образ. HTTP LAN требует cookie без Secure; production HTTPS — с Secure. Origin — точный разрешённый список, не wildcard.
