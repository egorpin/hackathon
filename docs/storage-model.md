# Склад

Источник: пользовательская модель `PixelArtistry_lowpoly_00016.glb`.
Игровой файл: `client/public/assets/models/storage.glb`, серверный тип `warehouse`.

Обработка: `tools/models/optimize_base.py INPUT.glb OUTPUT.glb --straight-panels`.
Сохранены геометрия и UV; текстура очищена до однотонных участков с границами
по граням модели, PNG 1024×1024. Удалены лишние карты и неиспользуемые буферы.
Ширина 1.6 м, основание на Y=0. Цветные панели поддерживают цвет игрока.
Бетонный фундамент подстраивается под рельеф.

Склад полностью статичный: без тряски, вращения и других анимаций.
Просмотр: `/base-review.html?model=storage`.
