# MCP для помощника Mars Colony

MCP запускается и завершается вместе с FastAPI: один Uvicorn worker, один экземпляр
мира, общий tick, блокировки и BufferedGameWriter. Дополнительный процесс, порт
или модель не нужны. Подключение будущего ИИ к tool calling пока не реализовано.

## Запуск и подключение

```bash
python -m pip install -r server/requirements.txt
PYTHONPATH=server uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 1
```

Streamable HTTP endpoint: `http://127.0.0.1:8000/mcp/`. Завершающий `/` избавляет
от HTTP redirect. Обычный Docker Compose запускает его автоматически; dev Vite,
production Nginx и HTTPS Nginx проксируют `/mcp` на сервер.

Каждый HTTP-запрос требует `Authorization: Bearer <mars_session>`: это действующий
токен обычной сессии, полученный через `/api/auth/login` или `/api/auth/register`
из cookie ответа доверенным кодом помощника. Cookie браузера без Bearer не даёт
доступа. Ключ администратора не подходит. Токен передаёт транспорт помощника,
а не модель в аргументах инструмента; его нельзя включать в промпт или логи.
Для удалённого доступа используйте HTTPS. Origin, если присутствует, проверяется
по общей политике сервера (точный разрешённый Origin или тот же LAN origin).

Игрок должен предварительно войти в мир через игру. MCP не создаёт игроков,
не выбирает команду и не голосует за начало игры. User/team/world всегда
вычисляются из текущей сессии, а не из аргументов модели. Logout и истечение
сессии прекращают доступ. Все ответы имеют `Cache-Control: no-store`.

Пример клиента официального Python SDK:

```python
import os
import httpx
from mcp import ClientSession
from mcp.client.streamable_http import streamable_http_client

async def inspect_world():
    async with httpx.AsyncClient(headers={
        'Authorization': f'Bearer {os.environ["MARS_PLAYER_SESSION"]}'
    }) as http:
        async with streamable_http_client(
            'http://127.0.0.1:8000/mcp/', http_client=http
        ) as (read, write, _):
            async with ClientSession(read, write) as session:
                await session.initialize()
                tools = await session.list_tools()
                world = await session.call_tool('get_world', {})
                return tools, world
```

## Инструменты и ограничения

| Инструмент | Действие и ограничения |
| --- | --- |
| `get_world` | DTO игрока: собственный инвентарь, склад и флот команды, видимые объекты, рецепты, состояние паузы. Приватные данные других команд скрыты. |
| `get_nearby_cells` | Клетки только в радиусе строительства 4.5 м от реальной позиции игрока: координаты, месторождения, занятость. |
| `place_building` | Бур, склад, генератор кислорода, солнечная панель или ветрогенератор. Дальность, коллизии, пригодность клетки, месторождение для бура и стоимость проверяет ядро; ресурсы списываются атомарно. |
| `remove_building` | Только союзное здание в радиусе взаимодействия; базовый купол защищён. Стоимость и содержимое возвращаются команде. Помечен destructive. |
| `pickup_resource` / `deposit_resource` | Союзное здание рядом; 1–50 целых единиц существующего переносимого ресурса. Проверяются наличие и вместимость. |
| `give_resource` | Другой игрок своей команды рядом, наличие ресурсов и свободное место в инвентаре получателя. |
| `survey_position` | Записать текущие координаты игрока, максимум 16 обследований. |
| `register_rover_point` | Только обследованные координаты, доступ к союзному офису, корректное имя и точность координат; максимум 12 точек. |
| `purchase_rover` | Доступ к офису, стоимость, свободное место появления, максимум 4 ровера команды. |
| `program_rover` | Только союзный остановленный ровер при доступе к офису; DSL до 512 байт, проверка парсером, без выполнения Python/shell. |
| `start_rover` | Только союзный ровер, доступ к офису, валидная программа и совпадающая ревизия. |
| `stop_rover` | Немедленная остановка союзного ровера без требования офиса. |

Изменения доступны только после начала игры и при снятой административной паузе.
Ограничения дальности для зданий совпадают с ядром (для взаимодействия радиус
зависит от размера клетки). MCP не предоставляет произвольный dispatch,
телепорт, сброс/запуск мира, генерацию ресурсов, изменение кислорода, админских
настроек или выполнение кода. Максимальное тело запроса — 16 KiB.

У каждого изменяющего инструмента обязателен `request_id`: канонический UUID в
нижнем регистре. Для нового намерения нужен новый UUID; при повторе после
сетевого сбоя — тот же UUID с теми же аргументами. Используется общая с игрой и
чатом дедупликация, сохраняемая вместе с состоянием. Повтор не списывает ресурсы
и не выполняет действие заново; другие аргументы дают `REQUEST_CONFLICT`.
Механизм сохранения общий с игрой: буферизованная запись SQLite; аварийное
завершение может потерять ещё не сброшенный буфер, штатное завершение его сохраняет.

Изменяющие инструменты возвращают обычный `action.result` в `structuredContent`:
проверяйте `payload.ok`, при отказе — `payload.code` (`OUT_OF_RANGE`,
`INSUFFICIENT_RESOURCES`, `FORBIDDEN`, `REVISION_CONFLICT` и т. д.). Ошибки схемы,
отсутствие игрока и `WORLD_PAUSED` возвращаются как MCP tool error (`isError`).
Неверная/просроченная сессия возвращает HTTP 401, недопустимый Origin — HTTP 403.
Перед записью программы и запуском ровера читайте `program_revision` из
`get_world.rover_fleet`; передавайте её в `expected_revision`.

## Проверка

```bash
.venv/bin/python -m pytest server/tests/test_mcp.py -q
```

Тесты используют настоящий MCP HTTP transport и официальный SDK-клиент,
проверяют авторизацию, отзыв сессии, изоляцию команд, дальность, стоимость,
вместимость, защищённые действия, паузу и повтор после загрузки сохранения.
