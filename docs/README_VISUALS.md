# Марс: графика, рельеф и модели

Игра работает локально. ComfyUI на Tesla-сервере нужен только для создания моделей; готовые одобренные GLB загружаются с локального игрового сервера.

## Запуск и проверка

Основной запуск: `start.cmd` из корня проекта, адрес `http://localhost:8000`. Требуется Docker Desktop. Подробности — [README_START.md](../README_START.md).

Для локальной разработки без Docker после установки зависимостей:

```powershell
cd client
npm run build
cd ..
$env:DATA_DIR = "$PWD/client/test-results/preview-data"
$env:STATIC_DIR = "$PWD/client/dist"
.venv/Scripts/python.exe -m uvicorn app.main:app --app-dir server --host 127.0.0.1 --port 18000
```

Открыть `http://127.0.0.1:18000/`. Это отдельное preview-сохранение. Изменения клиента требуют `npm run build` и обновления страницы, изменения Python — перезапуска сервера. Не удаляйте SQLite для обычного обновления.

## Что реализовано

- Процедурный рельеф: четыре широких холма и три кратера. Их положения, размеры и амплитуды определяет seed из ID мира. Один мир сохраняет рельеф после перезапуска; другой ID даёт другую генерацию.
- Сервер передаёт `world.terrain_seed`. Python и JavaScript используют одинаковый генератор; движение, прыжки, размещение ресурсов и отображение поверхности учитывают высоту. Номера и связи клеток сохраняются.
- Холмы имеют амплитуду 1,8–2,4 м, кратеры — глубину 1,2–1,65 м плюс небольшие неровности грунта. Размещение построек на склонах ещё требует визуальной проверки.
- Рельеф виден от первого лица и сверху. Сетка клеток в верхнем виде накладывается поверх поверхности.
- Рыжий процедурный грунт, мелкие декоративные камни через `InstancedMesh`, мягкая смена дня и ночи, солнце, звёзды и пыль.
- Ресурсы — отдельные процедурные россыпи в центре клеток, с отступом от края. Железо, сера, камень и лёд не генерируются в ComfyUI.
- Фонарик: `F`, прыжок: `Space`, бег: `Shift`, камера: `Tab`, панель: `H`.
- Цвет игрока применяется к персонажу и его постройкам. Для GLB перекрашиваются материалы с именем `Accent`.
- Высота персонажа и камеры дополнительно уменьшена вдвое относительно предыдущего масштаба 2/3. Ширина, руки и радиус столкновений сохранили прежний масштаб.

## Внутренние переключатели эффектов

Интерфейса для этих настроек пока нет. Значения по умолчанию находятся в `client/src/scene/visual-options.js` — все включены.

| Ключ | Что выключает |
| --- | --- |
| `rocks` | Декоративные мелкие камни и серверные пачки камней; ресурсные россыпи независимы |
| `resourceDeposits` | Объёмные россыпи ресурсов; данные, добыча и обозначения ресурсов остаются |
| `dust` | Пыль, включая обновление её частиц |
| `stars` | Звёзды |
| `sky` | Небесный купол; остаётся фоновый цвет сцены |
| `sun` | Видимый диск солнца; освещение и смена дня/ночи продолжаются |
| `hands` | Руки от первого лица |

Из кода, имеющего экземпляр сцены:

```js
scene.setVisualOptions({ rocks: false, dust: false, stars: false });
scene.setVisualOptions({ dust: true }); // остальные значения сохраняются
```

Или через существующую шину событий приложения:

```js
events.emit('graphics.effects', { rocks: false, dust: false });
```

Это API модулей, а не глобальные переменные браузерной консоли. Изменения применяются на следующем кадре, сохраняются при загрузке чанков и смене камеры. Настройки не записываются в localStorage и сбрасываются при создании новой сцены. Принимаются только известные ключи с boolean-значениями. Скрытые объекты остаются в памяти для быстрого повторного включения. Эти переключатели не меняют серверные столкновения или игровые правила.

## Модели и этапы одобрения

Шесть моделей: космонавт, бур на четырёх ногах с конусом, генератор кислорода, склад-здание, база-купол, робот-марсоход. Стиль — крупные low-poly формы без пальцев, мелких деталей, пола и подставок.

1. Одобренные референсы разделяются программно на виды 0° и 90°.
2. ComfyUI создаёт GLB на сервере. Готовность проверяется не чаще раза в пять минут.
3. Каждая модель показывается пользователю и исправляется до одобрения.
4. После одобрения выполняются подготовка анимаций и интеграция.

Запрошенное разрешение текстур теперь **1024×1024** (`texture_size`); разрешение самого TRELLIS pipeline остаётся `512` — это другая настройка. Увеличение текстуры само по себе не гарантирует устранения пятен генерации. Предыдущие кандидаты с текстурами 512 остаются отдельными черновиками.

Артефакты и состояние заданий: `artifacts/model-review/generated/`. Подготовленный workflow: `tools/comfyui/two-views/Tesla_TRELLIS_Two_Views_0_90.json`. Одобренные игровые модели: `client/public/assets/models/`, список — `manifest.json`. Черновики автоматически в игру не публикуются.

Риг космонавта и анимации механики пока подготовлены как заготовки: их нужно настроить и проверить на реальных моделях. Не считать наличие скрипта готовой анимацией. План: Idle/Walk/Run/Jump для космонавта; вращение и ход конуса бура; колёса, мачта и манипулятор марсохода.

## Производительность и тесты

Цель — стабильные 60 FPS на ноутбуке пользователя, пока без подтверждённого длительного замера. Используются объединённые/инстансные камни и ограниченное число частиц. HUD показывает FPS, p95 времени кадра, треугольники и вызовы отрисовки. Сценарий замера и изменения размера планеты: [visual-testing.md](visual-testing.md).

```powershell
cd client
npm test
npm run build
cd ..
$env:PYTHONPATH = 'server'
.venv/Scripts/python.exe -m pytest server/tests/test_terrain_jump.py server/tests/test_game.py
```

Также см. [этапы визуальной работы](visual-workflow.md) и [ComfyUI с двумя ракурсами](comfyui-two-views.md).
