# Кеширование моделей и текстур — 2026-11-01

- Vite формирует SHA-256 для каждой разрешённой GLB-модели в manifest.json. Изменение модели или встроенной текстуры меняет только её URL версии; ручное увеличение общей revision больше не требуется. Старые manifests совместимы.
- ModelCache: ограниченный LRU-кеш исходных GLB в памяти (8 МиБ), существующий постоянный Cache Storage (32 МиБ, 12 записей), объединение параллельных запросов. Копии буферов изолированы от изменений потребителем; очистка при dispose не допускает позднего заполнения памяти.
- Проверка GLB magic/version/length отклоняет повреждённые ответы. Ошибка декодирования инвалидирует кеш и повторяет загрузку с HTTP cache: reload.
- В GLB уже встроены текстуры. Экземпляры моделей разделяют геометрию и текстуры, а копия материала создаётся один раз на исходный материал внутри экземпляра. Цвета разных игроков независимы. При окончательном освобождении библиотеки закрываются декодированные ImageBitmap.
- Кеш четырёх процедурных текстур обозначений ресурсов сохранён; текстура поверхности Марса процедурная, скачивания не требует.
- HTTP и HTTPS Nginx: хешированные JS/CSS — immutable на год; стабильные пути моделей, manifest и HTML — обязательная ревалидация. Отсутствующий asset возвращает 404, не HTML.
- Без Cache Storage (в частности, HTTP по LAN-адресу) доступны память и обычный HTTP-кеш с ETag/304. Объём обычного HTTP-кеша контролирует браузер; лимиты 8/32 МиБ относятся к нашим кешам.
- Данные мира не добавляются в кеш ассетов; прежний предел мировых данных 10% сохранён.

Проверено: 75 тестов, production build, Docker healthcheck. В отдельном Edge-контексте три запроса модели: одна сеть, один memory hit, один Cache Storage hit. На работающем Nginx условный запрос модели вернул 304; хешированный JS — immutable; manifest — no-cache. HTTPS-конфигурация изменена аналогично, но HTTPS/LAN-сценарий в этом прогоне не запускался.
