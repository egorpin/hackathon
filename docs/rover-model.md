# Марсоход

Источник: `PixelArtistry_lowpoly_00017 (2).glb`, пользовательская модель робота.
Игровой файл: `client/public/assets/models/rover.glb`.
Размер: 6 245 204 → 77 472 байт. Текстура PNG 1024×1024,
очищенная палитра, прямые границы цветов по граням модели.

Обработка: `tools/models/optimize_base.py INPUT.glb OUTPUT.glb --straight-panels`.
Геометрия и UV сохранены. Цветные панели поддерживают цвет владельца.
В игровой сцене размер уменьшен до 0.6 м по максимальному горизонтальному
габариту для текущего радиуса ровера 0.3 м. Колёса стоят на поверхности.
Фундамента и тряски нет; вращение колёс и анимация манипулятора пока не добавлены.

Сцена отображает роверы из серверных снимков, интерполирует положение и направление,
заменяет временную форму после загрузки модели и удаляет исчезнувшие роверы.
Просмотр: `/base-review.html?model=rover` (увеличенный для осмотра).
