# Отчёт по клиентской части

Этот отчёт сохраняет результаты автора ветки frontend. После включения `309ee3c` в main повторно пройдены 15 JS-тестов и production-сборка Vite 6.4.5. Браузерные измерения ниже в ходе слияния повторно не выполнялись. Backend уже предоставляет авторизацию и чат, gameplay — автономное ядро; отсутствует именно их сквозная интеграция с клиентом. Актуальные расхождения и задачи: [status.md](status.md), [protocol.md](protocol.md).

Обновление геометрии: скопирован goldberg-hexgrid (MIT, commit 51d110b), прежний ручной fixture заменён экспортом GP(12,0). 1442 клетки: 12 пятиугольников и 1430 шестиугольников. Подробности, новые файлы и запуск — [goldberg.md](goldberg.md). Проверено 6 Python-тестов и 12 JS-тестов; обе камеры в preview сохраняют 3,75% данных, показания FPS около 95–120 в headless Edge. Генератор, зависимости, лицензия и адаптер находятся в tools/; dev middleware — client/dev/goldberg-preview.js; отрисовка общих полигонов — client/src/scene/polygon-geometry.js.

Реализована самостоятельная клиентская часть; обязательное многопользовательское демо пока не завершено из-за отсутствующих серверных и UI-зависимостей. README и agents_client.md прочитаны вместе с протоколом и планом участника 1.

## Изменённые файлы

- client/src/scene/world-scene.js — оболочка, серверные полигоны, выбор клетки/preview, модели построек, точки взаимодействия, игроки, камеры, instancing, GPU dispose, измерение FPS.
- client/src/scene/motion.js — касательный базис, непрерывное движение/перенос heading на сфере, сферическое расстояние, интерполяция.
- client/src/scene/controls.js — Pointer Lock, клавиатура, защита от залипания клавиш и ввода в формах.
- client/src/scene/fixture.js — отдельный dev-only пример.
- client/src/net/client.js — ws/wss от location, seq, revision, reconnect, повтор значимых команд по request_id.
- client/src/net/world-cache.js — UTF-8 байты, входящие резервы, пределы 5%/10%, eviction.
- client/src/net/runtime.js и events.js — связь сцены, транспорта, кеша и UI.
- client/src/main.js, style.css, client/index.html — запуск и диагностическая панель.
- client/package.json, package-lock.json — npm test, Vite 6.4.5.
- client/tests/ — модульные и браузерные проверки; client/.gitignore — локальные артефакты проверки.
- docs/client-integration.md — предложенные DTO, расхождения протокола, интерфейс UI и порядок интеграции.

Сервер, игровая логика, README, общий docs/protocol.md и client/src/ui/ не менялись.

## Реально проверено

- npm test: движение у северного/южного полюсов и экватора (30000 шагов), интерполяция, UTF-8, пределы кеша, 5000 последовательных загрузок, очередь, дубликаты, некорректные размеры, URL, revision gap, seq, повтор request_id.
- npm run build: production Vite/Three.js собирается; fixture отсутствует в dist.
- npm audit после обновления Vite: 0 уязвимостей.
- Headless Microsoft Edge, 1365×900: обе камеры, переключение не меняет счётчик (3,75% в preview с экспортом Голдберга), клавиатурное движение, четыре независимые вкладки fixture, нет pageerror.
- Измерение в малой локальной fixture-сцене: около 120 FPS. Это не показатель на целевых ноутбуках и не нагрузочный тест настоящего мира.
- Скриншоты обеих камер сохранены локально в client/test-results/ и визуально просмотрены.

Повтор: cd client && npm ci && npm test && npm run build. Браузерная проверка запускается из корня с запущенным Vite: node client/tests/browser-check.cjs. Нужны Playwright и установленный Edge; путь к внешней установке Playwright можно задать PLAYWRIGHT_MODULE. Playwright не добавлен в зависимости продукта.

## Ограничения

- Реальные два/четыре сетевых клиента, cookie-вход, строительство/перенос ресурсов, сохранение, серверные столкновения и LAN/offline-сценарий пока не проверяются: соответствующий сервер отсутствует. Четыре fixture-вкладки не являются мультиплеером.
- reconnect проверен на подменном socket, не на настоящем сервере.
- Pointer Lock подключён; ручная проверка на целевых LAN-браузерах остаётся. Есть резервное управление взглядом стрелками.
- Геометрия теперь экспортируется из скопированного генератора; игровой сервер должен подключить JSON-чанки, выбор игроков для площадок и правила мира.
- Учёт байтов требует согласования сериализации и дополнительных offer/accept/release с участником 2. Подробнее в client-integration.md.
- Рецепты, инвентарь, авторизация, чат и агенты относятся к участникам 2–4; клиент предоставляет события/команды, но их продуктовые экраны не подменены фиктивными реализациями.
- Грубая полигональная оболочка передаётся отдельно от подробных клеток и не содержит полную карту. В production нет CDN, внешних шрифтов, IndexedDB или service worker.
- Vite предупреждает о размере основного JS (~524 KB, gzip ~135 KB); основной объём — локальная библиотека Three.js.

Следующий интеграционный шаг: согласовать docs/client-integration.md с участниками 2–4 и подключить реальный сервер, затем выполнить сценарий docs/demo.md и обновить этот отчёт фактическими результатами.
