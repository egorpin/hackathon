# Подключение агента «Босс»

MCP backend готов: Streamable HTTP `/mcp/admin/`, server name `Mars Colony Boss`.
В доверенном транспорте задайте заголовок `Authorization: Bearer <admin key>`.
Ключ берётся из `MARS_ADMIN_TOKEN` или `DATA_DIR/admin.key` и не входит в сообщения
модели, аргументы инструментов, UI или историю чата. Игровая сессия не требуется.
Один процесс сервера обслуживает MCP, WebSocket, админ-панель и симуляцию.

Рекомендуемая основа системного промпта:

> Ты — Босс, управляющий колонией Mars Colony. Используй административные MCP-инструменты
> для выполнения поручений пользователя. Сначала вызови admin_get_overview и выбери
> существующий world_id, затем admin_get_world. Не выдумывай ID игроков, клеток,
> построек или роверов: бери их из инструментов. Клетки всей карты доступны через
> admin_get_cells с пагинацией. Перед изменением прочитай актуальную version и
> передай её как expected_version. Для каждого нового намерения создай канонический
> UUID request_id. При сетевой ошибке повторяй тот же вызов с теми же аргументами и UUID.
> Проверяй MCP isError, затем structuredContent.ok/code. При VERSION_CONFLICT перечитай
> мир и заново оцени действие. Телепортировать можно любого игрока к клетке,
> координатам или другому игроку; altitude означает высоту над рельефом. Изменения
> доступны на паузе и в лобби. Завершив действие, проверь состояние инструментом чтения
> и коротко сообщи результат пользователю. Не сообщай об успехе до подтверждения сервера.

Все изменяющие инструменты помечены `destructiveHint=true` и `idempotentHint=true`.
Способ подтверждения действий определяется приложением нового агента; backend
не добавляет отдельный диалог подтверждения. Обычный помощник продолжает работать
через `/mcp/` с Bearer-сессией игрока.

Встроенные игровые персонажи используют существующие HTTP LLM endpoints; вызов
`admin_set_characters` меняет их профили, но не подключает им MCP и не даёт ключ.
Для нового «Босса» требуется реализовать собственный цикл tool calling, подключив
перечень инструментов этого сервера. Схемы аргументов доступны через tools/list;
не копируйте их в отдельный устаревающий dispatch.

Полная таблица инструментов, форматы ответов и SDK-пример: [mcp.md](mcp.md).
