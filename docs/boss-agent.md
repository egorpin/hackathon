# Босс

Босс (`agent_id=boss`) доступен в существующем списке рядом с Марсиком.
Использует общую локальную модель Ollama, отдельную историю и сжатую память.
Профиль: `content/agents/boss.json`. Зарегистрирован через `admin.characters`:
добавляется и в ранее сохранённые наборы персонажей; явное отключение сохраняется.

## Текущий этап

Доступны диалог, планирование и объяснение состояния игры. MCP управления будет
предоставлен другим участником команды в отдельной ветке. Исполнение действий
пока отсутствует. `agent.prompt_messages` дополнительно сообщает модели это
ограничение независимо от редактируемого промпта персонажа.

## Интеграция будущей ветки

- Сохранить ID `boss` и существующие `/api/agent/ask` и `/api/agent/ask/stream`.
- Добавить отдельную ветку исполнения для Босса в `agent.complete` и
  `agent.stream_complete`: запрос модели → вызовы MCP → результаты → ответ.
- Заменить временное ограничение в `prompt_messages` фактическим списком
  доступных инструментов; обновить профиль и подпись `updateAgentRole`.
- Определить серверную авторизацию администраторов до включения инструментов:
  выбор персонажа сам по себе не должен выдавать административные полномочия.
- Выполнять изменения только в текущем авторизованном игровом мире;
  подтверждать результат реальным ответом инструмента и синхронизацией мира.
- Текущий `/mcp` является player-scoped и не содержит полного административного
  API. Его ограничения не снимаются этой подготовкой.

Готовность: Босс виден в списке, диалог отделён от Марсика, отключение через
настройки персонажей действует, просьба изменить мир пока не меняет состояние.
