# База

Источник: `PixelArtistry_lowpoly_00012.glb` (пользовательская модель).
Игровой файл: `client/public/assets/models/dome_base.glb`.

- 998 треугольников, геометрия и UV сохранены.
- Цветовая текстура: палитровый PNG 1024×1024, три однотонных цвета без JPEG-артефактов.
  Мелкие вкрапления заменяются преобладающим цветом окружения; границы крупных панелей сохраняются.
- Удалены неиспользуемые буферы, карты свечения, нормалей и металлического блеска;
  материал матовый. Удалены дополнительные цвета вершин, влияющие на цвет текстуры.
- Исходный размер файла: 5 020 108 байт; текущий размер выводит скрипт оптимизации.
- Основание выровнено по Y=0, ширина 1.6 м соответствует текущей коллизии построек.
- Оранжевые участки окрашиваются в цвет владельца тем же шейдером, что скафандр.
- В меню: «База», серверный тип `dome_base`, стоимость 5 руды.
  Производства ресурсов и специальных функций базы пока нет.
- Просмотр модели: `/base-review.html`.
- Под всеми постройками автоматически создаётся серый бетонный фундамент.
  Он выступает на 15 см с каждой стороны; верх расположен на 12 см выше
  максимальной из девяти проб рельефа под зданием, низ заглублён на 20 см
  относительно самой низкой пробы. Цвет игрока на бетон не влияет.

Повторная оптимизация (нужен Python с Pillow):

```text
python tools/models/optimize_base.py INPUT.glb client/public/assets/models/dome_base.glb
```

Исходная модель не изменяется. Потёртости и мелкие пятна в игровой текстуре удалены.
