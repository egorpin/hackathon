# Локальный контент

Агенты используют общий локальный Ollama, но отдельные профили, базы знаний и персональную память. Профиль лежит в `agents/<agent_id>.json`, а имя JSON-базы указывается в поле `knowledge`. Это позволяет добавлять новых агентов без загрузки второй копии модели.

`knowledge/expedition_examples.json` содержит 1000 вариантов вопросов. Сервер выбирает до шести похожих примеров и передаёт их модели как справку; весь файл в контекст не загружается. Старые сообщения периодически сжимаются в `agent_memory`, последние восемь реплик передаются дословно. Размер окна задаёт `MARS_AI_CONTEXT` (по умолчанию 32768).

Банк примеров пересоздаётся детерминированно командой `python tools/generate_agent_examples.py`. Факты в карточках нужно обновлять вместе с механиками игры.

Участник 4 добавляет характеры в `agents/`, проверенные факты и задания в `knowledge/`.
Контент включается в серверный образ; облачные сервисы не нужны.
